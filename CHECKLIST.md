# Чек-лист соответствия ТЗ — AI-генератор постов для Telegram

- [x] FastAPI-приложение и модульная архитектура (DDD)
- [x] Конфигурация через переменные окружения (`pydantic-settings`)
- [x] Асинхронная база данных SQLAlchemy 2.0 + Alembic миграции
- [x] Интеграция Celery + Celery Beat для периодических задач (парсинг каждые 30 минут)
- [x] Парсинг новостей из Telegram-каналов (Telethon) и веб-сайтов (RSSParser)
- [x] Фильтрация новостей по ключевым словам и языку
- [x] AI-генерация постов через OpenAI API с системным промптом, emoji и CTA
- [x] Публикация сгенерированных постов в Telegram (с защитой от дублей и FSM-статусами)
- [x] REST API эндпоинты для управления источниками (`/api/sources/`)
- [x] REST API эндпоинты для ключевых слов (`/api/keywords/`)
- [x] REST API эндпоинты для истории постов и ручного тестирования генерации (`/api/posts/`, `/api/generate/`)
- [x] Автоматизированное тестовое покрытие (Pytest Coverage 97%)
- [x] Контейнеризация (Docker & Docker-Compose)
